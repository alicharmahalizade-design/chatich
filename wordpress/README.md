# انتقال دوریان به وردپرس (چایلد-تم + Page Template)

این پوشه یک **چایلد-تم** آماده است که صفحهٔ فرود دوریان را به‌صورت یک قالب برگه
(«Dorian Landing») به وردپرس اضافه می‌کند، **بدون تغییر قالب فعال شما**. استایل‌ها و
اسکریپت‌ها فقط روی همان برگه بارگذاری می‌شوند، پس بقیهٔ سایت دست‌نخورده می‌ماند.

```
dorian-child/
├─ style.css            ← هدر چایلد-تم (نام قالب والد را اینجا تنظیم کنید)
├─ functions.php        ← فقط روی این قالب، CSS/JS را با ترتیب درست enqueue می‌کند
├─ template-dorian.php  ← خود صفحهٔ فرود (Template Name: Dorian Landing)
└─ assets/              ← css / js / vendor / img / video / fonts
```

## ۱) نام پوشهٔ قالب والد را تنظیم کنید (تنها کار دستی لازم)

فایل `style.css` را باز کنید و در خط `Template:` نام **پوشهٔ** قالب فعال‌تان را بگذارید.
برای پیدا کردن نام پوشه: پیشخان → نمایش → قالب‌ها، یا در میزبان وب پوشهٔ
`wp-content/themes/` را ببینید. مثلاً اگر قالب فعال `astra` است:

```
Template: astra
```

> اگر این خط با پوشهٔ قالب والد نخواند، وردپرس چایلد-تم را فعال نمی‌کند.

## ۲) آپلود و فعال‌سازی

- کل پوشهٔ `dorian-child` را در `wp-content/themes/` آپلود کنید (FTP یا فایل‌منیجر هاست).
- یا از آن یک فایل zip بگیرید و از پیشخان → نمایش → قالب‌ها → افزودن → بارگذاری قالب، نصبش کنید.
- سپس **چایلد-تم را فعال کنید** (قالب والد باید از قبل نصب باشد).

## ۳) ساخت برگهٔ فرود و تنظیم به‌عنوان صفحهٔ اصلی

1. پیشخان → برگه‌ها → افزودن برگه. عنوان مثلاً «خانه». محتوا را خالی بگذارید.
2. در نوار کناری، **ویژگی‌های برگه ← قالب → «Dorian Landing»** را انتخاب کنید و
   برگه را منتشر کنید.
3. پیشخان → تنظیمات → **خواندن** → «نمایش در صفحهٔ نخست» را روی **یک برگهٔ ثابت**
   بگذارید و «صفحهٔ نخست» را همان برگهٔ «خانه» انتخاب کنید. ذخیره کنید.

تمام شد — دامنهٔ اصلی شما حالا صفحهٔ فرود دوریان را نشان می‌دهد.

## سکشن فروشگاه (ووکامرس)

اگر افزونهٔ **WooCommerce** فعال باشد، یک سکشن «فروشگاه» به‌صورت **خودکار** بالای
بخش رزرو نمایش داده می‌شود:

- **جدیدترین ۸ محصول** را داینامیک از ووکامرس می‌کشد (با اضافه/حذف محصول در پیشخان،
  همین‌جا هم به‌روز می‌شود).
- قیمت‌ها مستقیم از ووکامرس می‌آیند (تخفیف هم نشان داده می‌شود).
- دکمهٔ هر کارت **«افزودن به سبد» با AJAX** است؛ یک **آیکون سبد شناور** هم گوشهٔ صفحه
  تعداد آیتم‌ها را زنده نشان می‌دهد.
- دکمهٔ **«مشاهدهٔ فروشگاه»** به صفحهٔ فروشگاه ووکامرس لینک می‌دهد.

اگر ووکامرس نصب/فعال نباشد یا محصولی نباشد، این سکشن به‌سادگی نمایش داده نمی‌شود و
بقیهٔ صفحه دست‌نخورده می‌ماند. سبد و تسویه‌حساب، صفحات استاندارد خود ووکامرس هستند.

> نکته: اگر «افزودن به سبد» بدون رفرش کار نکرد، در ووکامرس → تنظیمات → محصولات،
> گزینهٔ «فعال‌سازی دکمه‌های افزودن به سبد به‌صورت AJAX در بایگانی‌ها» را روشن کنید.

## نکته‌ها

- **فونت پینار** به‌صورت محلی از `assets/fonts/` لود می‌شود (در `site.css`). اگر مرورگر
  فونت را نشان نداد، مطمئن شوید نوع فایل `.woff2` در سرور مجاز است.
- **ویدیوی ۳۶۰ درجه** (`assets/video/services-360.mp4`، ~۱.۴ مگابایت) داخل قالب است؛
  اگر CDN یا کش دارید، همان‌جا هم سرو می‌شود.
- اگر افزونهٔ **کش/بهینه‌سازی** (مثل LiteSpeed/WP Rocket) دارید و چیدمان به‌هم ریخت،
  «ترکیب/تعویق جاوااسکریپت» را برای این برگه غیرفعال کنید؛ ترتیب اسکریپت‌ها مهم است
  (gsap → ScrollTrigger → lenis → app.js → custom.js).
- برای به‌روزرسانی محتوا/استایل بعداً، کافی است فایل‌های داخل `assets/` را جایگزین کنید؛
  نسخه‌ی کش به‌صورت خودکار با زمان تغییر فایل تازه می‌شود.

## صفحات داخلیِ هماهنگ (نسخهٔ ۲.۰)

از این نسخه، قالب علاوه بر لندینگ، **همهٔ صفحات داخلی** را هم با همان طراحیِ لاکچری
(پالت، فونت، طلا، هدر/فوترِ مشترک) نمایش می‌دهد — سبک و سریع و بدون اسکرول‌جکینگِ سنگین.
این کار با افزودنِ تمپلیت‌های استاندارد به چایلد-تم انجام شده و لندینگ دست‌نخورده مانده است.

فایل‌های تازه در `dorian-child/`:

- `header.php` / `footer.php` — پوستهٔ مشترک (هدرِ لوگو+منو+CTA، فوترِ چندستونه).
- `home.php` / `index.php` / `archive.php` / `search.php` — **مقالات و بایگانی** (کارت‌های خبری).
- `single.php` — **تک‌مقاله** (بدنهٔ خوانا + مقالاتِ مرتبط + دیدگاه‌ها).
- `page.php` — برگهٔ عمومیِ ادیتور.
- `template-about.php` — **درباره ما** (محتوا از پنل).
- `template-contact.php` — **تماس با ما** (تلفن/آدرس/ساعات/نقشه + فرمِ تماس با `wp_mail`).
- `woocommerce.php` — پوششِ فروشگاه و **تک‌محصولی**؛ استایل از `assets/css/internal.css`.
- `404.php` / `comments.php` — صفحهٔ «یافت نشد» و دیدگاه‌های تم‌دار.
- `assets/css/internal.css` + `assets/js/internal.js` — استایل و اسکریپتِ سبکِ صفحاتِ داخلی.

### راه‌اندازی صفحات (یک‌بار)

1. **درباره ما / تماس با ما:** پیشخان → برگه‌ها → افزودن. در «ویژگی‌های برگه ← قالب»
   به‌ترتیب **«درباره ما — Dorian»** و **«تماس با ما — Dorian»** را انتخاب و منتشر کنید.
   محتوا را از پیشخان → **نمایش → تنظیمات دوریان** (تب‌های «درباره ما» و «تماس با ما») ویرایش کنید.
2. **مقالات:** پیشخان → تنظیمات → **خواندن** → برای «برگهٔ نوشته‌ها» یک برگهٔ خالی
   (مثلاً «مقالات») بسازید و انتخاب کنید. لیستِ نوشته‌ها با کارت‌های دوریان نمایش داده می‌شود.
3. **منو:** در **نمایش → فهرست‌ها** یک منو بسازید و در محلِ «منوی اصلی دوریان (هدر)» بگذارید
   (مثلاً: خانه، درباره ما، مقالات، تماس با ما). اگر منو نسازید، منوی پیش‌فرض نمایش داده می‌شود.
4. **تک‌محصولی:** با فعال بودنِ ووکامرس، صفحهٔ فروشگاه و تک‌محصول خودکار پوستهٔ دوریان می‌گیرند.

### پنل تنظیماتِ پیشرفته

پیشخان → **نمایش → تنظیمات دوریان**؛ در تب‌های: عمومی، رنگ‌ها، تایپوگرافی، هدر، فوتر،
شبکه‌ها، درباره ما، تماس با ما، مقالات، محصول، لینک‌ها، کد سفارشی (CSS/JS سراسری) و تیم —
تقریباً هر چیزِ قالب بدون کدنویسی قابل تغییر است. رنگِ برند و CSS سفارشی روی **کل سایت** اعمال می‌شوند.

## نکته‌ها

- اگر افزونهٔ **کش/بهینه‌سازی** (مثل LiteSpeed/WP Rocket) دارید و چیدمانِ *لندینگ* به‌هم ریخت،
  «ترکیب/تعویق جاوااسکریپت» را برای آن برگه غیرفعال کنید؛ ترتیب اسکریپت‌ها مهم است
  (gsap → ScrollTrigger → lenis → app.js → custom.js). صفحاتِ داخلی به این ترتیب وابسته نیستند.
- **فرمِ تماس** با `wp_mail` ارسال می‌شود؛ برای تحویلِ مطمئن، یک افزونهٔ SMTP نصب کنید و در
  تبِ «تماس با ما» ایمیلِ گیرنده را تعیین کنید (خالی = ایمیلِ مدیر سایت).
- این قالب همچنان یک **چایلد-تم** روی `hello-elementor` است؛ فقط تمپلیت‌های استاندارد را
  override می‌کند و برگه‌های ساخته‌شده با المنتور (Canvas/Full-width) دست‌نخورده می‌مانند.
