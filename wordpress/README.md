# انتقال دوریان به وردپرس (چایلد-تم + Page Template)

این پوشه یک **چایلد-تم** آماده است که صفحهٔ فرود دوریان را به‌صورت یک قالب برگه
(«Dorian Landing») به وردپرس اضافه می‌کند، **بدون تغییر قالب فعال شما**. استایل‌ها و
اسکریپت‌ها فقط روی همان برگه بارگذاری می‌شوند، پس بقیهٔ سایت دست‌نخورده می‌ماند.

```
dorian-child/
├─ style.css            ← هدر چایلد-تم (نام قالب والد را اینجا تنظیم کنید)
├─ functions.php        ← فقط روی این قالب، CSS/JS را با ترتیب درست enqueue می‌کند
├─ template-dorian.php  ← خود صفحهٔ فرود (Template Name: Dorian Landing)
└─ assets/              ← css / js / vendor / img / video / fonts
```

## ۱) نام پوشهٔ قالب والد را تنظیم کنید (تنها کار دستی لازم)

فایل `style.css` را باز کنید و در خط `Template:` نام **پوشهٔ** قالب فعال‌تان را بگذارید.
برای پیدا کردن نام پوشه: پیشخان → نمایش → قالب‌ها، یا در میزبان وب پوشهٔ
`wp-content/themes/` را ببینید. مثلاً اگر قالب فعال `astra` است:

```
Template: astra
```

> اگر این خط با پوشهٔ قالب والد نخواند، وردپرس چایلد-تم را فعال نمی‌کند.

## ۲) آپلود و فعال‌سازی

- کل پوشهٔ `dorian-child` را در `wp-content/themes/` آپلود کنید (FTP یا فایل‌منیجر هاست).
- یا از آن یک فایل zip بگیرید و از پیشخان → نمایش → قالب‌ها → افزودن → بارگذاری قالب، نصبش کنید.
- سپس **چایلد-تم را فعال کنید** (قالب والد باید از قبل نصب باشد).

## ۳) ساخت برگهٔ فرود و تنظیم به‌عنوان صفحهٔ اصلی

1. پیشخان → برگه‌ها → افزودن برگه. عنوان مثلاً «خانه». محتوا را خالی بگذارید.
2. در نوار کناری، **ویژگی‌های برگه ← قالب → «Dorian Landing»** را انتخاب کنید و
   برگه را منتشر کنید.
3. پیشخان → تنظیمات → **خواندن** → «نمایش در صفحهٔ نخست» را روی **یک برگهٔ ثابت**
   بگذارید و «صفحهٔ نخست» را همان برگهٔ «خانه» انتخاب کنید. ذخیره کنید.

تمام شد — دامنهٔ اصلی شما حالا صفحهٔ فرود دوریان را نشان می‌دهد.

## نکته‌ها

- **فونت پینار** به‌صورت محلی از `assets/fonts/` لود می‌شود (در `site.css`). اگر مرورگر
  فونت را نشان نداد، مطمئن شوید نوع فایل `.woff2` در سرور مجاز است.
- **ویدیوی ۳۶۰ درجه** (`assets/video/services-360.mp4`، ~۱.۴ مگابایت) داخل قالب است؛
  اگر CDN یا کش دارید، همان‌جا هم سرو می‌شود.
- اگر افزونهٔ **کش/بهینه‌سازی** (مثل LiteSpeed/WP Rocket) دارید و چیدمان به‌هم ریخت،
  «ترکیب/تعویق جاوااسکریپت» را برای این برگه غیرفعال کنید؛ ترتیب اسکریپت‌ها مهم است
  (gsap → ScrollTrigger → lenis → app.js → custom.js).
- برای به‌روزرسانی محتوا/استایل بعداً، کافی است فایل‌های داخل `assets/` را جایگزین کنید؛
  نسخه‌ی کش به‌صورت خودکار با زمان تغییر فایل تازه می‌شود.
- این چایلد-تم چیزی از قالب والد را بازنویسی نمی‌کند؛ بقیهٔ برگه‌ها/نوشته‌ها مثل قبل
  با قالب والد نمایش داده می‌شوند.
